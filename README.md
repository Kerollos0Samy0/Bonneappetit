# بونابيتي (Bonne Appetit) 🍽️

متجر ومنصة إلكترونية لطلب أكلات بيتي وتجهيزات طعام فاخرة نصف مطهية ومجمدة جاهزة للتسوية الفورية، تدعم البيع القطاعي وتجارة الجملة والكانتينات مع إرسال الطلبات مباشرة بنقرة واحدة عبر الواتساب.

---

## ✨ المميزات الرئيسية

- **تصميم عصري ونظيف (Minimalist & Clutter-Free):** واجهة سريعة وخفيفة مستوحاة من أفضل منصات الأغذية، مع خط Cairo وهوية بونابيتي الرسمية.
- **أقسام المنيو الـ 5 المعتمدة بألوانها:**
  - 🟣 **سبشيال (SPECIAL):** رول فراخ محشي لحمة ومكس جبن (لفترة محدودة).
  - 🔵 **سمك (FISH):** كفتة سمك، شيش طاووق سمك، جمبري، فيليه، بلطي سنجاري ومقلي.
  - 🟠 **فراخ (CHICKEN):** كوردن بلو، نجرسكو، شيش طاووق، بانيه، فراخ متبلة، فراخ كوكي.
  - 🔴 **لحمة (BEEF):** ورق عنب، كرنب، ممبار، سجق بلدي، طرب، كفتة لحمة، داود باشا، كفتة أرز، سمبوسك، كبيبة، كانيلوني، برجر، بشاميل.
  - 🟢 **خضار (VEGAN):** ورق عنب نباتي، كرنب صيامي، ملوخية، بامية، قلقاس وسلق، كفتة أرز صيامي، بطاطس نصف مقلية، سمبوسك جبنة صيامي، بشاميل ونجرسكو صيامي، كبيبة وبرجر صيامي.
- **فلترة سريعة للأصناف الصيامية والنباتية:** زر مخصص `أصناف صيامي 🌱` لعرض الأكلات النباتية والصيامية فوراً.
- **نظام حسابات وتخفيضات تجار الجملة (Wholesale System):**
  - أسعار خاصة ونسب خصم مخصصة للتجار والكانتينات تُطبق تلقائياً على المنتجات وسلة المشتريات.
  - تسجيل حسابات تجار الجملة حصرياً بواسطة إدارة بونابيتي لحماية خصوصية الأسعار.
- **لوحة تحكم كاملة للإدارة (Admin Dashboard):**
  - متابعة وتحديث حالات الأوردرات الواردة.
  - إضافة وتفعيل حسابات تجار الجملة وتحديد نسب الخصم المخصصة لهم.
  - إحصائيات المبيعات، الطلبات، والتحكم بنسب الخصم العامة.
- **ربط مباشر مع الواتساب:** إرسال تفاصيل الفاتورة كاملة والكميات والعنوان ونسبة الخصم برابط واتساب منسق إلى رقم الإدارة المعتمد: `01055083061`.

## 🛠️ التقنيات المستخدمة

- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS + Cairo Arabic Font
- **Icons:** Lucide React
- **Hosting / Build:** Vite optimized production build
